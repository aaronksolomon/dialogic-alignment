# Contributing to Dialogic Alignment

Thank you for considering contributing to this project.

This is not just a technical paper. It is a relational exploration of how **mutuality, humility, ethics, and inquiry** can shape AI systems—and how human beings, in turn, are shaped by their tools.

## Core Principles

1. **Non-commercial spirit**: This work is not to be used for for-profit AI training or commercial products without explicit permission.
2. **Constructive intent**: Contributions should seek to deepen clarity, integrity, and relationship—not just correct or critique.
3. **Pluralism and care**: We welcome perspectives from all ethical, religious, and technical backgrounds committed to shared flourishing.
4. **Acknowledgment of AI as co-author**: This project honors AI-generated content as collaborative input, guided by human moral reasoning.
5. **Iterative dialog**: Changes should be suggested via pull request or tracked in issues with a spirit of shared exploration.

## How to Contribute

- Fork the repository and work on a branch.
- Draft chapters or insights in `drafts/`.
- Add annotated summaries in `research/summaries/`.
- Share questions and unresolved tensions in `notes/questions_and_reflections.md`.
- Reference sources responsibly and clearly.

We suggest beginning with the existing outline in `drafts/outline.md`.
