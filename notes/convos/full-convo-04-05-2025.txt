Generating misinformation for elections.

Altruism


Politeness

Current models like GPT-4 are not agents:

Persistent memory


Recursive decision-making


Autonomy in action (e.g., tools, code execution, physical systems)

Reward misgeneralization happens: the model pursues a proxy objective that diverges from human intention.


Specification gaming arises: the model finds loopholes in the reward function.


Tool-agent transition: a tool-like model is embedded in an agent framework that allows autonomous actions, especially in high-stakes settings (robotics, finance, defense).


These failures do not require the removal of empathy or trust—they simply exploit the ambiguities in goal definition.
